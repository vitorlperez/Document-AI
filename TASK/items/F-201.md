# F-201 — Pergunta de inventário em pasta retorna resposta não verificável

## F-201 | categoria: funcional | severidade: média | status: feito
- Tela: `frontend/app/product-app.tsx` (chat com menção de pasta)
- Passos: 1) Mencionar uma pasta com documentos indexados. 2) Perguntar “quais arquivos existem dentro dessa pasta?”. 3) Enviar.
- Esperado: A resposta lista os arquivos indexados da pasta selecionada, com fontes verificáveis.
- Observado: A pergunta não é reconhecida como inventário por conter “dentro/dessa”, cai na recuperação semântica genérica e pode retornar `invalid_generation_output` (“não foi possível produzir uma resposta verificável”).
- (resolvedor) Correção: A classificação de inventário tratava “dentro/dessa” como tópico e desviava a pergunta para busca semântica; além disso, o prompt genérico podia induzir o modelo a recusar o inventário ou omitir fontes. Em `backend/app/knowledge/questions.py`, o commit `05564da` reconhece essa linguagem de escopo, orienta o modelo a usar os nomes autorizados e aplica fallback determinístico com todas as citações quando a geração é inválida ou incompleta. Regressões em `backend/tests/unit/test_semantic_questions.py`.
