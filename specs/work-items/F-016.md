# F-016 - RAG de produção com embeddings na ingestão e recuperação híbrida

**Status:** done

## Source and outcome

- Source specification: `specs/001-mvp-document-intelligence.md` F4, ADR-0003.
- User outcome: questions stay fast as the knowledge workspace grows because chunks are embedded during reconciliation and retrieval combines scoped lexical and semantic candidates before grounded generation.
- Non-goals: cross-workspace retrieval, autonomous actions, proprietary model fine-tuning, or sending unselected content to an AI provider.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| --- | --- | --- | --- |
| Chunk embeddings are created or refreshed only after a successful content change during ingestion. | Product + implementation | Approved | Removes surprise embedding work and latency from a user's question. |
| Candidate retrieval is scoped in SQL by organization and workspace before hybrid ranking. | Security + implementation | Approved | Preserves the tenant and workspace invariant. |
| The current JSON vector storage is retained for this MVP increment; retrieval limits candidates before cosine reranking. | Implementation | Approved | No unverified pgvector runtime dependency; a later migration can add ANN without changing the contract. |
