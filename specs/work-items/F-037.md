# F-037 - Revisão do MVP, experiência de produto e landing page Arquivio

**Status:** done

## Source and outcome

- Source specification: 001 MVP §§1–15; user authorizes product/functionality/UI improvements and public LP. Brand Arquivio and Portuguese confirmed.
- User outcome: clearer activation, reliable library/chat interactions, cohesive responsive UI, public landing page leading to existing authentication.
- Non-goals: new providers, billing/pricing promises, changes to tenant access or data retention, production deployment.

## Product review findings

- Library management lacked pagination even though the API paginates children; users could not reach later files.
- Navigation/search responses could arrive out of order and overwrite current results.
- Session failures were hidden from anonymous users; there was no visible retry action.
- Mobile conversation context selection was separated from the composer.
- Organization onboarding and unavailable-company screens exposed internal jargon.
- Saved-query endpoints already exist but reusable questions are absent from the main UI.
- Backend regression fixtures lagged the `screen_hint`/`max_age` authentication contract. Correcting the fakes restores 32 regression checks without modifying authentication behavior.
- Production readiness remains distinct from this product pass: real WorkOS/Google/OpenAI end-to-end testing needs the configured external environment. Browser QA in F-037 uses an isolated synthetic identity and document dataset.
- Scaling limitation observed: embeddings are currently JSON values and semantic ranking loads scoped chunks into Python. A measured pgvector migration remains future work, not an implied performance claim in the LP.
