# F-007 - Saved queries usage controls and failure visibility

**Status:** done

## Source and outcome

- Source specification: spec 001 §§3, 6, 7, 9–15 and ADR-0003.
- User outcome: members own saved searches; Admin sees safe processing failures; costly operations respect tenant limits.
- Non-goals: billing, reporting, alerts and automatic deletion for overage.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| --- | --- | --- | --- |
| Pilot monthly defaults: 500 docs, 2 GB processed, 1M embedding tokens and 1,000 questions; block new costly operations only. | User/product | Approved | ADR-0003 |
