# F-032 - Padronizar páginas de equipe e tools

**Status:** done

## Source and outcome

- Source specification: pedido direto de padronização de navegação e design.
- User outcome: o menu superior mostra “Tools” como destino de integrações; Equipe e Tools usam uma superfície visual consistente com Biblioteca e Consultas, com título, contexto e painéis alinhados ao design do produto.
- Non-goals: mudar permissões de membros, fluxos de convite, OAuth, sincronização, rotas ou APIs.

## Decisions

| Decision | Owner | Status | ADR / rationale |

| Usar contêiner de página com cabeçalho e painéis internos para Equipe e Tools | Product | approved | Padroniza a experiência sem alterar o conteúdo operacional. |
