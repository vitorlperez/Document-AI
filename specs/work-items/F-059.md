# F-059 - Fontes citadas como lista compacta de documentos

**Status:** done

## Source and outcome

- Source: user request of 2026-09-23; `specs/001-mvp-document-intelligence.md` F4.
- Show each source document used in a supported answer once, as a compact linked row with document and tool identity, without excerpt text or a displayed maximum.
- Remove the fixed `MAX_CITATIONS = 5` truncation from evidence selection. Keep a text-size budget for generation so prompt size and cost remain bounded; this budget is not a count of citations.
- Keep the evidence excerpt in the API contract for traceability and existing clients, but do not display it in the conversation. No database migration.

## Decisions

| Decision | Owner | Status | Rationale |
| --- | --- | --- | --- |
| Document list represents sources actually cited by generation, deduplicated by source identity. | User intent and existing F4 rules | Approved | Avoid claiming every retrieved document supported the answer. |
| Do not show excerpts or a citation-count badge. | User | Approved | Compact interface. |
| Retain a character budget and at most two pieces of evidence per document for model input, without a numeric citation cap. | Implementation | Approved | Bound cost and latency while allowing more than five distinct source documents. |
| Keep existing `citations` JSON shape and excerpt field. | Implementation | Approved | Avoid a breaking public API change; front end omits excerpt. |
| Generated answers without valid cited evidence remain insufficient evidence. | Existing spec | Approved | Preserve source-backed answers. |
