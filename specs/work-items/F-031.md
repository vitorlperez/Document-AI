# F-031 - Rolagem independente nos workspaces

**Status:** done

## Source and outcome

- Source specification: pedido direto para separar a rolagem dos componentes nas telas Biblioteca e Consultas.
- User outcome: no desktop, cada coluna do workspace — estrutura, conteúdo/conversa e contexto/gestão — conserva sua própria posição de rolagem e pode ser percorrida sem movimentar as outras colunas.
- Non-goals: alterar dados exibidos, rotas, APIs, permissões, comportamento mobile ou a semântica de sincronização.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| --- | --- | --- | --- |
| Aplicar painéis com rolagem independente a partir do breakpoint desktop XL | Product | approved | Em telas estreitas, as colunas empilham e a rolagem única evita áreas extremamente pequenas. |
| Manter a rolagem das mensagens na área central de Consultas | Product | approved | A conversa não deve mover os painéis de fontes e contexto. |

## Validator report

- Blocking: None.
- Important: None.
- Suggestions: The Consultas source panel retains its existing inner scrollable file list inside an independently scrollable column. This is not clipping, but manual browser QA with a long source list is recommended to confirm the nested-scroll feel is acceptable.
- Independent evidence: At `min-width: 1280px`, the workspace root is height-constrained and the child grid becomes a min-height-zero flex item. Its two asides and non-Consultas main receive `overflow-y: auto` and `overscroll-behavior: contain`; the Consultas main remains a flex column with overflow hidden while its existing `flex-1 overflow-y-auto` message pane becomes min-height-zero and contained. This keeps each desktop column independent without scrolling the workspace root. Below XL, the media rules do not apply and the workspace root retains vertical scrolling, preserving the stacked/mobile layout without clipping. Validator reran lint and production build successfully.
- Gate decision: Approved. Browser verification remains a recommended visual QA step for desktop nested scrolling and narrow viewport ergonomics; no blocking CSS or build regression was found.
