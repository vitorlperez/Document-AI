# F-035 - Deploy de piloto Oracle Always Free

**Status:** done

## Source and outcome

- Source specification: 001 MVP, requisitos de jobs assíncronos, isolamento e observabilidade; decisão do usuário por Oracle Always Free, mantendo OpenAI.
- User outcome: o produto roda com custo fixo de infraestrutura zero em uma VM Oracle Always Free, sem expor Postgres, Redis ou API diretamente à internet.
- Non-goals: provisionar conta Oracle, registrar domínio, alterar credenciais de terceiros, substituir OpenAI ou prometer disponibilidade/SLA de produção.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| --- | --- | --- | --- |
| Hospedar API, worker, Postgres e Redis na mesma VM Oracle Always Free | Product | approved | Melhor caminho sem custo fixo para o piloto; a separação lógica continua por containers. |
| Usar Caddy para HTTPS e proxy de mesmo domínio | Engineering | approved | Evita CORS entre domínios e não expõe serviços internos; certificados são renovados automaticamente. |
| Publicar frontend pelo servidor de produção do Vinext | Engineering | approved | `vinext start` serve o bundle SSR gerado pelo build sem usar o servidor de desenvolvimento. |
| Restringir `POSTGRES_PASSWORD` a hexadecimal URL-safe | Engineering | approved | A senha é interpolada em `DATABASE_URL`; `openssl rand -hex 32` evita caracteres reservados sem armazenar uma segunda versão codificada. |

## Validator report

- Blocking: nenhum.
- Important: a senha do Postgres foi documentada como hexadecimal URL-safe e o healthcheck da API agora consulta `/health/ready`, validando disponibilidade do banco.
- Suggestions: configurar destino externo e periodicidade de backup antes de dados reais; adicionar HSTS depois que o domínio final estiver estabilizado.
- Independent evidence: o validador construiu a pilha em projeto Docker isolado; migração terminou com código 0, API/Postgres/Redis ficaram saudáveis e worker respondeu `pong`. `https://localhost/` retornou o frontend, `https://localhost/api/health/ready` retornou `{"status":"ready"}`, HTTP redirecionou com 308 para HTTPS e apenas Caddy publicou portas 80/443. A pilha e os volumes temporários foram removidos ao final.
- Gate decision: passed.
