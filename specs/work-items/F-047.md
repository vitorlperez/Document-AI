# F-047 — Fluxo de conexão e sincronização por ferramenta

- status: done
- source specification: `specs/001-mvp-document-intelligence.md`
- owner: `frontend/app/product-app.tsx`, `backend/app/api/integrations.py`

## Critérios de aceitação

- A tela da ferramenta mostra claramente se a conexão está ativa ou requer reconexão.
- A reconexão é oferecida quando a validação do catálogo remoto falha.
- O botão de sincronização abre um modal na própria tela da ferramenta.
- O modal separa espaços já sincronizados de pastas ainda disponíveis.
- Cada espaço já sincronizado possui ação explícita de re-sync.
- O endpoint de espaços retorna metadados de seleção para distinguir pastas sincronizadas.
