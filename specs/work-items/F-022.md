# F-022 - Navegação compacta no cabeçalho

**Status:** done

## Source and outcome

- Source specification: `specs/001-mvp-document-intelligence.md`; F-021 conversational Company Library.
- User outcome: navigate Bibliotheca, Consultas, Equipe, and Google Drive from a compact dropdown in the header, near the signed-in email, instead of a persistent side menu.
- Non-goals: changing routes, backend authorization, data access, or the retrieval scope. “Biblioteca” and “Consultas” are contextual destinations within the existing Company workspace.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| Replace the persistent navigation rail with a header dropdown | Product + implementation | approved | User-requested density reduction; keeps the active workspace visually focused |
| Add Consultas as the explicit entry to the Company conversation screen | Product + implementation | approved | Makes returning from Equipe/Google Drive unambiguous |
| Preserve visibility restrictions: Equipe only Owner, Google Drive only Owner/Admin | Implementation | approved | Existing role behavior must not change |
| --- | --- | --- | --- |
