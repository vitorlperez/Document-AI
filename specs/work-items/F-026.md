# F-026 - Consolidação da navegação e telas legadas

**Status:** complete

## Source and outcome

- Source specification: `specs/001-mvp-document-intelligence.md` — navegação por Company, biblioteca unificada, consulta com evidências e integrações.
- User outcome: uma navegação coerente para o workspace unificado, sem atalhos duplicados nem páginas antigas de consulta por pasta.
- Non-goals: excluir dados, endpoints, sincronizações ou consultas salvas; alterar regras de tenant, papéis, autenticação ou RAG.

## Decisions

| Decision | Owner | Status | ADR / rationale |

## Acceptance criteria and test matrix

| Criterion | Test layer | Evidence |
| --- | --- | --- |
| Given a user opens the header menu on the Company dashboard, when they choose **Consultas**, then the chat section is focused; when they choose **Biblioteca**, then the sources section is focused. | Build + source inspection | Distinct section navigation and accessible targets. |

## Impact assessment

- API/data: no endpoint, stored document, embedding, sync, or saved-query deletion. The unused folder-query client is removed only.
- Authorization/tenant: Company UUID routes and role guards remain unchanged. The removed route has no replacement authorization surface.
- Failure states: no new network operation; anchor navigation degrades to the workspace URL if the user is on another product page.
- Performance/observability: deleting unused client components reduces shipped client code. No logging or metrics change is needed.
