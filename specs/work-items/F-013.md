# F-013 - Retorno web após conexão Google Drive

**Status:** done

## Source and outcome

- Source specification: F2 in `specs/001-mvp-document-intelligence.md` and ADR-0002.
- User outcome: after granting Google Drive read-only access in a browser, the user returns to the authenticated Company integration screen, rather than an API JSON document.
- Non-goals: changing OAuth scopes, changing token storage, adding another source provider, or exposing OAuth codes/tokens to the frontend.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| --- | --- | --- | --- |
| Preserve programmatic callback contract | Implementation owner | Approved | Return JSON unless the request explicitly accepts HTML; a Google browser navigation receives a 303 redirect. This avoids breaking the existing API contract while giving the OAuth browser flow product-appropriate completion. |
| Redirect target | Implementation owner | Approved | Build only from configured `PUBLIC_APP_URL`, the organization UUID authenticated by the one-time state, and a fixed integration path. No OAuth state, authorization code, token, or arbitrary return URL enters it. |
