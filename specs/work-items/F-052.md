# F-052 - Estruturação de chunks e evidências para bibliotecas heterogêneas

**Status:** done

## Source and outcome

- Source specification: `specs/001-mvp-document-intelligence.md` F3/F4; `specs/work-items/F-016.md`.
- User outcome: retrieval preserves document structure and page context, embeds enough context to disambiguate chunks, and uses a relevant set of evidence across heterogeneous files with citation-grounded abstention.
- Non-goals: Chroma/pgvector/vector database migration, schema migration, OCR, model/provider change, exhaustive structured extraction of Google Docs/PDF layout.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| --- | --- | --- | --- |
| Keep clean chunk text separate from enriched searchable/embedding text; include document title and available section context in the latter. | Implementation | Approved | Preserves citation excerpts while disambiguating vectors. |
| Chunk extracted blocks with a 500-word target and 60-word overlap, preserving page/section boundaries. | Implementation | Approved for pilot | Bounded deterministic heuristic without a tokenizer dependency; quality fixture and future evaluation can tune it. |
| Bump processing version to v2 to rebuild unchanged documents under the new chunker. | Implementation | Approved | Existing idempotent reconciliation uses the processing version to detect pipeline changes. |
| Limit final evidence to two chunks per document, eliminate excerpt containment duplicates, then cap at five. | Implementation | Approved for pilot | Improves source coverage without changing auth filters or citation contract. |
| Keep current JSON embedding storage and in-memory similarity search. | User | Approved | Vector database evaluation/migration is explicitly deferred. |

## Known limits

- The target is measured in whitespace-delimited words, not the provider's exact tokenizer. A later calibrated evaluation can tune the target and overlap.
- Google Docs extraction remains plain text; PDF extraction preserves page boundaries but not layout/tables. DOCX headings and tables and Markdown headings carry available context.
- Evaluation is deterministic/unit-level and does not substitute for a labeled production corpus or human answer-quality review.
- Vector database migration is excluded from this item and remains a later evolution.
