# F-006 - Semantic questions and citations

**Status:** done

## Source and outcome

- Source specification: spec 001 §§3, 5–11, 13–15 and ADR-0003.
- User outcome: a folder-scoped question produces only cited supported facts or `insufficient_evidence`.

## Validator report

- Blocking: none.
- Important: citation IDs establish provenance but do not independently prove natural-language entailment; add an extractive or entailment guard before high-stakes use. Current local JSON vectors rank all scoped chunks in memory with sequential provider calls; pgvector/HNSW and a reproducible 10k benchmark are required before claiming the scale target.
- Suggestions: evaluate an extractive/entailment guard against the fixed evaluation fixture before pilot expansion.
- Independent evidence: validator verified filters execute before embedding, ranking and generation; inactive/cross-organization access is denied before provider calls; citations are nonempty, unique, exact integer positions and bounded. It independently ran Ruff, 13 focused tests, migration upgrade/downgrade and the 110-test PostgreSQL suite.
- Gate decision: approved.
