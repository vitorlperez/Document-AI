# F-009 - Ambiente local Docker do frontend e backend

**Status:** done

## Source and outcome

- Source specification: `specs/001-mvp-document-intelligence.md` §14 (approved local Docker Compose infrastructure).
- User outcome: start the web UI, API, PostgreSQL, Redis, migration step and Celery worker together with one local command.
- Non-goals: production deployment, real OAuth or LLM credentials, and changes to domain data or authorization rules.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| Runtime topology | Implementation owner | Approved | API and worker use the existing modular-monolith backend image; PostgreSQL and Redis remain local dependencies. |
| Browser origins | Implementation owner | Approved | Frontend is available at `localhost:3000`, API at `localhost:8000`; API `PUBLIC_APP_URL` is the explicit allowed local UI origin. |
| --- | --- | --- | --- |
