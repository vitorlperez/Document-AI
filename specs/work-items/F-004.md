# F-004 - Asynchronous ingestion and document lifecycle

**Status:** done

## Source and outcome

- Source specification: spec 001 §§3, 5–8, 10–15 and ADR-0003.
- User outcome: Admin starts a manual full-folder sync; eligible documents become idempotent records/chunks and failures remain visible without losing valid work.
- Non-goals: OCR, vectors, search, polling/Changes API and storing original binaries.
