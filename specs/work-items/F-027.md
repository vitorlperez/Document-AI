# F-027 - Recuperação RAG de conteúdo e metadados

**Status:** done

## Source and outcome

- Source specification: `specs/001-mvp-document-intelligence.md`, F4 — busca textual considera título e texto extraído; perguntas usam somente chunks autorizados da mesma organização e pasta com citações.
- User outcome: perguntas sobre os arquivos sincronizados e informações presentes neles encontram evidência no contexto selecionado e devolvem resposta citada.
- Non-goals: mudar o provedor de IA, enviar uma pasta inteira sem limite ao modelo, ampliar uma pergunta para toda a Company, usar conteúdo de outra organização/pasta ou reduzir a exigência de citação.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| --- | --- | --- | --- |
| Perguntas de inventário explícito de arquivos recuperam uma evidência por documento, limitada por `MAX_CITATIONS` | Engineering | Approved | Metadados de nome já são autorizados e pertencem ao mesmo escopo; evita depender de similaridade de texto para listar arquivos. |
| Um termo exato e distintivo no título ou conteúdo pode resgatar um candidato mesmo acompanhado de termos genéricos | Engineering | Approved | Corrige o falso negativo de perguntas como “há informações sobre Vitor?”, preservando score e escopo para os demais candidatos. |
| Resposta gerativa continua obrigando citação de fontes selecionadas | Product invariant | Approved | Não altera a regra de confiança do MVP. |

## Acceptance criteria and test matrix

| Criterion | Test layer | Evidence |
| --- | --- | --- |
| Given a ready workspace with two embedded documents, when a Member asks which files are in that context, then one scoped citation per listed document is supplied to the answer generator, bounded by the citation limit. | Unit evaluation | Provider evidence contains the two document names and no foreign documents. |
| Given a chunk containing a distinctive exact name such as `Vitor`, when a Member asks a natural-language question containing that name plus generic words, then that chunk is eligible even if the hybrid score is below the normal semantic threshold. | Unit evaluation | Supported answer cites the matching document. |
| Given a semantically weak query with no exact distinctive match, when retrieval runs, then it still returns `below_evidence_threshold` and does not invoke generation. | Unit regression | Existing negative retrieval case remains green. |
| Given a document in another organization or workspace, when either recovery mode runs, then it is never passed to the answer generator. | Unit regression | Existing tenant/folder-scoping tests remain green. |

## Impact assessment

- API/data: no schema or public response-contract change. The existing cited-question endpoint returns the same shape.
- Authorization/tenant: both recovery modes operate only after `require_member_access` and only on already scoped `(organization_id, workspace_folder_id)` rows.
- Failure states: an empty folder, missing embeddings, invalid generation, low-evidence question and provider errors retain their existing explicit outcomes.
- Performance/observability: inventory retrieval uses the already loaded scoped candidate set, bounded to one chunk per document and `MAX_CITATIONS`; safe count/mode metrics are logged without names, questions or content.
