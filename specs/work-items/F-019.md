# F-019 - Navegador Finder da Biblioteca

**Status:** done

## Source and outcome

- Source specification: `specs/001-mvp-document-intelligence.md`, F-014 selectable Drive scopes, F-018, and `ADR-0006`.
- User outcome: browse the Company Library like Finder: open a provider, open folders, and see their direct child folders and indexed files without returning to a list of isolated syncs.
- Non-goals: live Google Drive browsing, a document previewer, cross-workspace RAG, or a new external integration.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| Folder metadata is persisted as a provider-neutral library projection during a successful synchronization. | Engineering | Approved | `ADR-0006`; the UI never needs to call Drive live to render a previously indexed library. |
| Library-node URLs use local UUIDs; provider IDs remain opaque storage keys. | Product + engineering | Approved | Matches the project UUID URL/API policy. |
| Empty and failed remote branches are excluded from the browser; a legacy indexed document without folder metadata is shown under the source root. | Product | Approved | A useful safe fallback until its next synchronization enriches the path. |
| --- | --- | --- | --- |

## Acceptance criteria and test matrix

| Given a successfully indexed Drive file in a nested selected folder, when the Company Library is opened, then its provider root and ancestor folders can be opened successively until the file is visible. | Unit + API | Tree projection fixture |
| Given files synchronized by different selections share a Drive source, when browsing, then their common folders/files are one navigable tree rather than sync cards. | Unit + UI/API | Single-source tree response |
| Given a previously indexed document lacks path metadata, when browsing its source root, then it remains visible as a root-level file. | Unit | Legacy fallback fixture |
| Given a caller requests a node UUID from another organization, when browsing children, then the API returns no node details or children. | API | Cross-organization denial test |
| Given a folder with thousands of direct children, when it is opened, then child results are paged and bounded to 100. | Unit + API | Pagination contract |
