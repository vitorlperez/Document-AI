# F-033 - Compactar citações por arquivo

**Status:** done

## Source and outcome

- Source specification: pedido direto para reduzir a poluição visual das fontes nas respostas da IA.
- User outcome: cada documento citado aparece em uma única linha compacta; seu nome é um link para a origem quando disponível e indica quantos trechos daquele arquivo sustentam a resposta.
- Non-goals: mudar a recuperação RAG, remover evidências do contrato da API, alterar citações usadas pela geração ou expor conteúdo adicional.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| --- | --- | --- | --- |
| Agrupar citações somente para apresentação, por `document_id` | Product | approved | Mantém o contrato e a rastreabilidade bruta da API; a interface reduz apenas a redundância visual. |
| Exibir uma contagem de trechos para arquivos repetidos | Product | approved | Comunica que a resposta foi apoiada por mais de uma passagem do mesmo arquivo. |

## Validator report

- Blocking: None.
- Important: None.
- Suggestions: Add a focused unit test for `compactCitations` with repeated document IDs, distinct document IDs and the first citation lacking `source_url`; this is small logic whose behavior is otherwise validated only by review.
- Independent evidence: `compactCitations` groups only in the frontend by `document_id`, preserves first-seen document ordering and increments `citation_count` for every repeated document. A grouped row retains the source URL from the same document's first citation, or fills it only from a later citation with that identical `document_id`; it cannot receive a URL from another document group. The raw API call/result is unchanged, and compaction occurs solely before rendering the message. `EvidenceCard` renders exactly one compact row per grouped record, keeps a permitted `source_url` as the row anchor, shows `N trechos` only when N is greater than one, and retains the page label for a single citation. Static TypeScript review found no incorrect keys or cross-document link path.
- Gate decision: Approved. The container build and local HTTP response independently establish that the frontend compiles and starts. Host ESLint remains inconclusive due to the observed shared-runtime stall, but no static or container-build blocker remains.
