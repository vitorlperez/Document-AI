# F-018 - Biblioteca unificada da Company

**Status:** done

## Source and outcome

- Source specification: `specs/001-mvp-document-intelligence.md`, F-014 selectable Drive scopes, and the Company Library decision in `ADR-0006`.
- User outcome: every completed synchronization contributes to one Company Library rather than appearing as a separate knowledge space; overlapping Drive files are represented once, with their source provenance retained.
- Non-goals: cross-workspace search/RAG, a new connector, changing uniform-access consent, or exposing unindexed source content.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| A workspace folder remains a synchronization/provenance boundary, while the Company Library is a read projection over all eligible workspace folders in the organization. | Product + engineering | Approved from the user request | `ADR-0006`; preserves the existing retrieval invariant. |
| A visible library item is deduplicated by source UUID and external provider file ID, never by filename. | Engineering | Approved | Makes repeated/overlapping syncs one logical item without conflating different files. |
| The first increment exposes indexed documents only; failed or unselected remote files do not become Company Library content. | Product + security | Approved | Keeps the current consent and extracted-content boundary intact. |
| --- | --- | --- | --- |

## Acceptance criteria and test matrix

| Given two completed sync scopes from one source contain the same external file, when a member opens the Company Library, then that file appears once and retains its source/workspace provenance. | Unit + API | Deduplication fixture and API contract |
| Given a member opens the Company Library, when indexed documents exist in multiple selected scopes, then one organization-scoped collection includes each eligible document. | API | Positive list response |
| Given a caller from another organization or no active membership, when it requests a Company Library, then no item metadata is returned. | API | 403/isolation test |
| Given a large library, when listing it, then the API returns a bounded first page and a stable total. | Unit + API | Pagination test and query limit review |
