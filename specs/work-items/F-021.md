# F-021 - Biblioteca em layout conversacional

**Status:** done

## Source and outcome

- Source specification: `specs/001-mvp-document-intelligence.md`, F-018 through F-020.
- User outcome: use the Company Library in a focused, notebook-like workspace where the conversation is central, sources remain easy to browse, and sync/search context is visible without splitting the experience into disconnected cards.
- Non-goals: copying Google or NotebookLM branding, changing synchronization/RAG APIs, adding a document preview, or widening retrieval beyond a selected workspace folder.

## Decisions

| Decision | Owner | Status | ADR / rationale |
| Use a three-pane responsive workspace: sources, conversation, and context/operations | Product + implementation | approved | Familiar notebook interaction model while retaining the existing Company Library and Finder navigation |
| Keep AI retrieval gated by an explicit synchronized workspace-folder selection | Product + implementation | approved | F-004/F-020 privacy invariant; visual changes must not turn Company Library into a global RAG corpus |
| Keep existing library, sync, and search endpoints | Implementation | approved | UI-only delivery; avoids unnecessary data/API risk |
| --- | --- | --- | --- |
